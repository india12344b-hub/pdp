# PDP Homepage

Responsive React + Vite implementation of the supplied PDP homepage design.

## Run

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Notes

- Mobile-first responsive breakpoints are included.
- The visual hierarchy follows the supplied design: hero → proof → people → how it works → recruiters → market → CTA → footer.
- Current photography uses Unsplash image URLs as temporary visual assets. Replace them with PDP-owned assets before production.
- The profile carousel is functional and the mobile navigation opens from the hamburger button.
